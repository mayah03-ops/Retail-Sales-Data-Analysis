# Retail Sales Data Analysis

## Project Overview
This project analyzes retail sales data using Python to identify
sales trends, profitable product categories, and regional performance.

## Objectives
- Analyze total sales and profit.
- Compare sales across product categories.
- Identify the most profitable categories.
- Compare profit across regions.
- Identify profitable and loss-making subcategories.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Findings
- Total sales: 2,296,195.81
- Total profit: 286,242.20
- Technology generated the highest sales and category profit.
- The West region generated the highest regional profit.
- Tables recorded the largest loss among subcategories.

## Project Structure
- data/ — Dataset
- charts/ — Generated visualizations
- sales_analytics.ipynb — Analysis notebook

## Conclusion
The analysis identifies profitable product categories and regions
while highlighting subcategories that may require further investigation.
